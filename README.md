# Bank Marketing Campaign Analysis

# Overview
This project analyzes data from a Portuguese banking institution’s direct marketing campaign. The goal is to understand the key factors that influence whether a client subscribes to a term deposit product, and to build predictive models that can support more effective marketing strategies.

# Dataset
Source: bank-full.xlsx dataset (from UCI Machine Learning Repository)

Scope: Contains client demographic information, contact data, and campaign outcomes.

Target Variable: y (binary: whether the client subscribed to a term deposit)

# Objectives

Explore and visualize the dataset to uncover key patterns.

Identify demographic and campaign-related features that correlate with positive client responses.

Develop classification models to predict subscription likelihood.

Compare model performance using key evaluation metrics.

# Models Implemented

Logistic Regression

Decision Tree Classifier

Random Forest Classifier

Gradient Boosting Classifier

K-Nearest Neighbors (KNN)

Naive Bayes

# Evaluation Metrics

Accuracy

Precision

Recall

F1-Score

Confusion Matrix

# Key Tasks

Load and preprocess the dataset

Perform exploratory data analysis (EDA) with visualizations

Encode categorical variables and scale features

Train and evaluate multiple classification models

Interpret results and offer actionable insights

# Tools & Libraries

pandas, numpy

matplotlib, seaborn

scikit-learn
